AI.

What I've built with it, and how it fits together.

I run my own work on a system of AI agents I designed and built: they capture my ideas, plan my week, work my inbox and calendar, and hand everything back on one dashboard each morning. Here is how it works, and the tools I built along the way.

How it works.

Four layers, from a passing thought to a finished day.

Capture

Ideas and tasks get caught the moment they happen, by voice, so nothing depends on remembering it later.

Wispr Flow notes · Siri · Apple Reminders · Codex voice for new projects

Plan & build

One weekly planning session in Claude turns everything captured into plans, and local agents build on it.

Claude Code · training, nutrition and study coaches · a project pipeline from kickoff to shipped app

Act

A master assistant agent takes the plan and hands each piece to the specialist agent that owns it.

Email triage · scheduling · errands and shopping · social media · travel

Deliver

Everything lands where I already look: my calendar, my inbox, long-term memory, and one dashboard.

Google Calendar · Gmail · Supabase memory · daily dashboard · GitHub

What I've built.

Systems I use every day.

A team of agents that plans my week

Each agent is a folder of rules that configures its own Claude session. A calendar agent plans across ten Google Calendars, an email agent sorts Gmail into four bins and drafts replies but never sends, and training, nutrition and study coaches hand their plans to each other and to the calendar.

Claude Code · Folder-agent pattern · MCP connectors · Cloud routines

A dashboard that rebuilds itself every morning

A local dashboard reads what every agent produced. At 5:30 each morning a scheduled task syncs the calendar, rebuilds a snapshot, and republishes it, so the day is waiting when I wake up. Money and health data never leave the Mac.

Next.js · TypeScript · Scheduled tasks · claude.ai artifacts

A second brain the agents can search

Long-term memory on PostgreSQL with pgvector (Supabase) and Voyage AI embeddings, reached from Claude through MCP connectors, so any session can recall notes, decisions, and back-burner ideas by meaning.

PostgreSQL/pgvector · Supabase · Voyage AI · MCP Connectors · Python

A skills library that runs every project

Reusable Claude skills that take an idea from a raw note to a shipped, reviewed build. Each one is a written procedure Claude loads on its own when the work calls for it, so every project runs the same way.

Claude skills · Markdown procedures · Trigger phrases

Fitness Coach Harness

A product, not just a personal tool.

The training agent runs on a generic coaching harness with no personal data in it, built so other coaches and clients can run it too. My own agent is its first test user, and every week of use goes into its test log.

AI-directed websites

Art direction with generated assets.

This site and my company's site were designed with AI as the production team: generated illustrations, photography, and a hero film, held to one design system and reviewed against the Laws of UX before launch.
