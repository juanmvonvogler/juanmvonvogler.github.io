Multi-Agent AI Operating System

In daily use since March 2026

Claude Code · Supabase Postgres/pgvector · Next.js · Wispr Flow

The problem

Email, calendars, and recurring workflows take time away from engineering work.

What I built

A system of agents run by Claude Code: each agent is a folder of rules that configures its own session, and a master assistant hands each piece of the plan to the specialist that owns it. The agents share a second brain on PostgreSQL with pgvector (Supabase) and Voyage AI embeddings, reached through MCP connectors, report to a Next.js dashboard, and a scheduled morning agent rebuilds the day before I wake up. Ideas enter by voice through Wispr Flow. Every project keeps a numbered decision log, with more than 100 decisions logged across four projects, and every new agent goes through the same four stage pipeline: research, design, build, QA.

Where it stands

The research and development started in 2025 on an Obsidian vault. I worked with ChatGPT before Claude and with Meta Muse for agent work, and I evaluate new tools as they come out.
